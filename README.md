# Drivelink 🚗

> Mais que carros, novos caminhos.
> Seu próximo carro está mais perto.

Drivelink é uma plataforma para vitrine de veículos seminovos e captação de pré-cadastros (*leads*).

## 📁 Estrutura do Monorepo

- `backend/`: API REST desenvolvida em Java 21 e Spring Boot 3.
- `frontend/`: Aplicação web desenvolvida em React + Vite.
- `docs/`: Documentação do projeto, protótipos e especificações de API.
